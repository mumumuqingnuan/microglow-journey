# 月隐·微光旅途

36 张图像卡组成的互动网页，包含一张微光、三张卡故事漫游与五步手记，以及洗牌、放大翻牌、光晕粒子、全屏、音乐、手记保存和结果图导出。

## 文件

- `index.html`：可独立运行的完整网页，卡面、样式和脚本均已内嵌。由原始 `microglow-journey.html` 原样复制，仅更改文件名。
- `microglow-journey-source.zip`：原始可编辑源代码，解压后参考其中的 README 与 package.json 进行维护。

## 运行与发布

直接用浏览器打开 `index.html`，或通过 GitHub Pages 访问。

GitHub Pages 使用 **Deploy from a branch → main → / (root)**。

维护时将更新后的独立网页保存为根目录 `index.html`，并同步更新源代码 ZIP。本仓库独立于 `moonveil-tarot`。
